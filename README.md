# 皇室战争 全部战旗图鉴

一个**离线可用的单文件网页图鉴**，收录《皇室战争》游戏内 **422 组战旗**（Battle Banner，共 835 件背景 / 前景部件）。 所有图像均已从本地精灵文件渲染打包，不依赖任何在线图床 —— 双击 index.html 即可浏览。

## 特性

| 数量 | 说明 |
| --- | --- |
| **422** | 战旗组数（背景 Background + 前景 Foreground 按精灵文件名自动配对） |
| **411** | 背景 + 前景齐全，卡片直接展示叠加后的游戏内效果 |
| **11** | 仅单件（只有背景或只有前景） |
| **835** | 部件总数（背景 413 · 前景 422，可在「单件视图」逐件浏览） |
| **3** | 开局默认拥有（黄 / 绿 / 紫三款默认战旗） |

交互功能：

- **双视图** —— 配对视图（背景 + 前景叠加 = 游戏内效果）/ 单件视图（按 CSV 原始行逐件浏览）
- **搜索** —— 名称 / 编号 / 资源文件名模糊匹配
- **筛选** —— 上架位置（Season 36–39 礼盒）、`背景 + 前景齐全`、`仅背景 / 仅前景`（单件视图）、`默认拥有`
- **排序** —— 战旗编号 / 名称 A→Z / 按上架位置分组
- **详情灯箱** —— 大图预览 + 背景 / 前景拆分展示，`←` `→` 翻页、`Esc` 关闭

## 快速开始

无需安装、无需联网，直接双击打开 `index.html`。

## 目录结构

```
.
├── index.html              # 自包含单文件页面（数据内联）
└── assets/
    └── banners/            # 835 张 PNG（背景 / 前景部件，170px 高）
```
